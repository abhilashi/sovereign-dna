## 2026-10-03 - Adding accessibility props to Framer Motion elements
**Learning:** When adding accessibility attributes (like `role`, `tabIndex`, `onKeyDown`) that are conditionally applied to an internal `framer-motion` element (e.g., when an `interactive` state is derived from `onClick`), do not expose these properties in the component's Props interface as it shadows caller values. Instead, group them into a typed `HTMLMotionProps<"div">` object and spread it (`<motion.div {...interactiveProps}>`) to keep JSX markup clean and maintainable. Framer-motion elements gracefully accept standard HTML DOM attributes natively.
**Action:** Always use `HTMLMotionProps` when conditionally generating accessibility attributes for Framer Motion wrappers inside custom components rather than extending standard React prop interfaces which can cause `onDrag` type conflicts.
