## 2024-11-21 - Clean JSX for Conditional Interactivity on Framer Motion Components
**Learning:** When conditionally applying multiple accessibility attributes (like `role`, `tabIndex`, `onKeyDown`) to an internal `framer-motion` element (e.g., `motion.div`), exposing these props in a custom wrapper component's interface can create a misleading API where passed values are shadowed. However, directly inserting them inline bloats the JSX. Grouping them into a typed `HTMLMotionProps<"div">` object and spreading it (`{...interactiveProps}`) keeps the JSX markup clean, maintainable, and prevents type conflicts with Framer Motion, while still delivering full keyboard accessibility when `onClick` is provided.
**Action:** Use typed `Partial<HTMLMotionProps<"div">>` objects to conditionally spread interactive accessibility attributes inside custom wrapper components instead of bloating inline JSX or unnecessarily exposing them on the component's public interface.
