## 2026-07-19 - Auto-focus inputs on quick prompt selection\n**Learning:** When building interfaces where users select predefined 'quick prompts' or clickable data points (like a Karyogram node) that populate a query input without auto-submitting, failing to programmatically focus the input introduces a point of friction. Users expect to immediately modify or submit the newly populated query.\n**Action:** Use `setTimeout(() => inputRef.current?.focus(), 0)` (or similar focus-deferral techniques) to ensure the input field seamlessly receives focus immediately after a click interaction populates it, saving the user a manual click.
