## 2026-07-12 - [Accessible Dynamic Zoom Text Indicator]
**Learning:** Screen readers need to be made aware of dynamic state changes that do not result from direct focus interactions. In our map visualizations, when users click zoom buttons (+ or -), the text label (e.g., 'Genome', 'Chromosome') updates automatically. Without explicit aria attributes, a screen reader user clicking the zoom button is not informed of the resulting zoom level change. Using `aria-live="polite"` ensures these text updates are read out, while `aria-atomic="true"` makes sure the entire text block is read when any part of it changes.
**Action:** When implementing dynamic text indicators that update based on user action elsewhere (like zoom level displays, progress indicators, or status text), always ensure they are wrapped in an element with `aria-live="polite"` and `aria-atomic="true"` to announce the change non-intrusively to screen readers.
