## 2026-08-26 - Interactive Card Keyboard Accessibility\n**Learning:** Interactive structural components (like `Card` wrapping `div` elements) assigned `onClick` handlers often miss full keyboard accessibility, breaking the tab sequence for screen readers and keyboard users.\n**Action:** When conditionally making a `div` interactive, group `role="button"`, `tabIndex={0}`, `onKeyDown` (for Enter/Space), and Tailwind `focus-visible` utility classes into a clean, typed object (e.g., `HTMLMotionProps<"div">`) to spread over the underlying element safely without exposing them in the component's API.
