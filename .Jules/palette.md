## 2025-05-18 - Making Framer Motion interactive divs accessible
**Learning:** When using Framer Motion's `motion.div` as an interactive element (like a Card with `onClick`), it lacks native semantic button accessibility. The `framer-motion` props natively accept HTML DOM attributes, but applying attributes conditionally can result in messy inline JSX.
**Action:** When conditionally applying accessibility properties (`role="button"`, `tabIndex={0}`, `onKeyDown`) to `motion.div`, group them into a typed `HTMLMotionProps<"div">` object and use JSX spreading (e.g. `{...interactiveProps}`). Include standard keyboard interaction handling (Space and Enter) and verify visible focus styling (e.g., `focus-visible:ring-1`). Do not expose these a11y props in the component's interface unless the caller is meant to override them.
