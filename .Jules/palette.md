## 2026-07-31 - Add keyboard accessibility to interactive Cards\n**Learning:** When creating custom interactive components (like a `Card` with an `onClick` prop) using non-semantic HTML elements like `div`, keyboard accessibility is crucial but often forgotten. Users navigating via keyboard must be able to focus the element and activate it using the 'Enter' or 'Space' keys, similar to a standard `<button>`.\n**Action:** Always conditionally spread a typed object of accessibility props (e.g., `role="button"`, `tabIndex={0}`, `onKeyDown`) onto the wrapping element when it becomes interactive. Also ensure visible focus styling (e.g., `focus:ring-1`) is conditionally applied so screen reader and keyboard users have a seamless experience.
