## 2024-11-09 - Accessible Interactive Structural Components
**Learning:** When making non-semantic structural components (like Cards or List items) interactive by passing an `onClick` handler, they must be augmented to function like true buttons for accessibility. This includes adding `role="button"`, `tabIndex={0}`, and `onKeyDown` handlers that listen for 'Enter' and 'Space' (and preventing the default scrolling behavior of 'Space'). Furthermore, `focus-visible` styling must be applied to ensure keyboard users can track their position on the page.
**Action:** When a component receives an `onClick` prop, automatically package and spread these necessary interactive HTML properties (e.g., using `HTMLMotionProps` for framer-motion components) onto the root element. Ensure explicit focus styling (like `focus-visible:ring-1 focus-visible:ring-accent focus:outline-none`) is conditionally added.
