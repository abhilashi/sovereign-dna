## 2024-10-18 - [Accessibility in Framer Motion Interactive Components]
**Learning:** When adding multiple accessibility attributes (like `role="button"`, `tabIndex={0}`, `onKeyDown`) to an internal `framer-motion` component like `<motion.div>` that derives its interactivity from an optional `onClick` prop, inline conditionally rendering these attributes can clutter the JSX significantly. Using `HTMLMotionProps<"div">` works well for strong typing.
**Action:** Group conditionally applied interactive attributes into an object typed with `Partial<HTMLMotionProps<"div">>` and spread it on the `<motion.div>` element (e.g., `{...interactiveProps}`). Do not expose these attributes to the parent component's Props interface to prevent shadowing. Add `focus-visible` styles to clearly indicate keyboard focus.
