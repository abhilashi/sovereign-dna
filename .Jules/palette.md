## 2026-09-25 - Card Component Keyboard Accessibility
**Learning:** When building custom interactive components using non-semantic HTML elements (like `div` or framer-motion's `motion.div`), they lack built-in keyboard accessibility. Providing `role="button"`, `tabIndex={0}`, and an `onKeyDown` handler for 'Enter' and 'Space' (including `e.preventDefault()` for 'Space' to prevent page scrolling) ensures users navigating with keyboards can interact with the element. Conditionally spreading a typed `HTMLMotionProps<"div">` object allows adding these only when the element is actually interactive, keeping the interface clean and preventing non-interactive elements from receiving focus.
**Action:** Group conditionally applied accessibility attributes for framer-motion components into a typed `HTMLMotionProps<"div">` object and spread it on the element. Provide `focus-visible:ring-1 focus-visible:ring-accent focus:outline-none` Tailwind classes to clearly indicate keyboard focus without affecting mouse users.
