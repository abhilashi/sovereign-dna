## 2026-08-12 - Added Keyboard Accessibility to Interactive Cards\n**Learning:** When making wrapper components like `Card.tsx` interactive by conditionally passing an `onClick` prop, they require full keyboard accessibility support (Enter/Space to trigger, Tab to focus, and a visible focus ring). Grouping these dynamic attributes into a typed `HTMLMotionProps<"div">` configuration object and conditionally spreading them ensures clean semantic HTML and type-safe Framer Motion markup without cluttering the component tree or generating conflicting empty attributes.\n**Action:** Always conditionally attach `role="button"`, `tabIndex={0}`, `onKeyDown`, and focus-visible classes to internal non-semantic elements when wrapping them with a dynamic interactive API.
