## 2024-06-06 - Making non-semantic interactive cards accessible
**Learning:** When using non-semantic elements like `div` or `motion.div` for interactive components (e.g., clickable Cards), they require explicit roles (`role="button"`), keyboard focus (`tabIndex={0}`), keyboard event handlers (`onKeyDown` for Enter and Space), and visible focus styling (e.g., `focus-visible` classes) to ensure accessibility for screen readers and keyboard users. Crucially, pressing Space must also call `e.preventDefault()` to stop the page from scrolling down.
**Action:** Always add semantic HTML and complete a11y attributes when converting a standard layout component into an interactive target. Check if the element handles clicks and make sure keyboard usage mirrors the click functionality safely.
