## 2024-10-26 - Accessible Interactive Framer Motion Divs
**Learning:** When making non-semantic Framer Motion elements (`motion.div`) interactive conditionally based on the presence of an `onClick` prop, they need proper keyboard support and screen reader context without adding redundant wrapper elements.
**Action:** Use a conditionally generated `HTMLMotionProps<"div">` object containing `role="button"`, `tabIndex: 0`, and an `onKeyDown` handler (for Enter/Space), and spread this object (`{...interactiveProps}`) onto the `motion.div`. Include `focus:outline-none focus-visible:ring-1 focus-visible:ring-accent` in the Tailwind classes for visible keyboard focus indication. Do not expose these a11y props in the component's public interface unless callers specifically need to override them.
