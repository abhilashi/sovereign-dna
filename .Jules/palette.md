## 2024-05-14 - Making Conditional Wrappers Accessible
**Learning:** Generic wrapper components like `Card` often become inaccessible interaction points when they accept an `onClick` prop but fail to adapt their semantics. Passing accessibility attributes down explicitly in a custom typed property (`HTMLMotionProps<"div">`) solves type conflicts while dynamically transforming static `div` elements into semantic interactive elements (`role="button"`, `tabIndex={0}`, keyboard support) without affecting purely structural usages.
**Action:** When creating layout primitives (Cards, Rows, Sections) that conditionally accept user interaction (`onClick`), always bundle semantic roles, keyboard handlers (Enter/Space), and visible focus styling as a conditional prop group rather than exposing them individually to the component's public interface.
