## 2025-01-20 - Adding keyboard accessibility to interactive motion.div Cards
**Learning:** When using `framer-motion` for interactive components (like `motion.div` acting as a button), it's important to make them fully keyboard accessible. Adding `onClick` alone only handles mouse/touch interactions. To support keyboard navigation, the element needs a `tabIndex={0}`, a `role="button"`, and an `onKeyDown` handler to listen for 'Enter' and 'Space' keys. Additionally, adding visible focus styles (e.g., `focus:outline-none focus-visible:ring-1 focus-visible:ring-accent`) is necessary so users navigating with the keyboard know which element is currently focused. Grouping these accessibility attributes into an `HTMLMotionProps<"div">` object and spreading them onto the `motion.div` is a clean way to apply them conditionally when the component is interactive.
**Action:** When building interactive custom components using non-semantic HTML elements like `div` or `motion.div`, always remember to add `role="button"`, `tabIndex={0}`, keyboard event handlers (`onKeyDown` for 'Enter' and 'Space'), and focus-visible styling to ensure the component is fully usable for keyboard and screen reader users.
